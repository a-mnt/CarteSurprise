# Carte cadeau d'anniversaire

Version corrigée :
- grattage souris + tactile fonctionnel ;
- photo nette, sans flou ;
- aucun texte par-dessus la photo ;
- texte d'instruction présent uniquement sur la couche à gratter ;
- compatible GitHub Pages.

## Ton image

Remplace `assets/cadeau.jpg` par ta vraie photo en gardant ce nom.

## GitHub Pages

Crée un dépôt GitHub, ajoute tous les fichiers, puis :
**Settings → Pages → Deploy from a branch → main → / (root)**.

La page sera ensuite accessible via l'adresse GitHub Pages de ton dépôt.
